# AI-Assisted Coding Rules
**Product:** Averin Health
**Last Updated:** 2026-06-03

---

## 1. Requirements

- All requirements must be written and reviewed by a human before coding begins.
- Requirements must be traceable — every line of code should map back to a stated requirement.
- Requirements changes during development must be reviewed and signed off by a human before the corresponding code is written or modified.

---

## 2. Unit Tests

- Unit tests must be defined by a human before coding begins (test-driven development).
- Tests define the acceptance criteria — AI-generated code is written to pass them, not the other way around.
- No requirement is considered implemented until its corresponding tests pass.

---

## 3. AI-Generated Code Review

Every file or function containing AI-generated code must include a header block:

```python
# -----------------------------------------------------------
# AI-GENERATED CODE — HUMAN REVIEW REQUIRED
# Generated by: [model name, e.g. Claude Sonnet 4.6]
# Date generated: YYYY-MM-DD
#
# Human reviewer: _______________
# Review date: _______________
# Changes made during review:
#   -
#   -
# Comments:
#
# Sign-off: _______________
# -----------------------------------------------------------
```

- The reviewer must read and understand the code, not just run it.
- Any changes made during review must be listed explicitly.
- Sign-off indicates the reviewer takes ownership of the code.

---

## 4. Traceability

A traceability document (`traceability_matrix.md`) must be continuously updated throughout development. For each requirement, it must record:

| Field | Description |
|-------|-------------|
| Requirement ID | Unique identifier (e.g. REQ-001) |
| Requirement | Full requirement statement |
| Relevant code | File paths and line numbers |
| Unit tests | Test file and test name(s) that verify the requirement |
| Verification method | Unit test / integration test / manual review |
| Human reviewer | Name |
| Review date | Date |
| Sign-off | Initials confirming requirement was reviewed and verified |

The traceability matrix must be updated before a requirement is marked complete — not after.
